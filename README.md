# My Orders UI - Android Assignment

This project is a UI implementation of the "My Orders" mobile application screen provided as an internship assignment by OceanX Agency.

## Features

- Android Native UI using Kotlin + XML
- RecyclerView style order cards
- Bottom Navigation
- Search Bar
- Filter & Sort Buttons
- Clean UI Design
- Responsive Layout
- Rounded Buttons and Cards

## Tech Stack

- Kotlin
- XML
- Android Studio

## Project Structure

- activity_main.xml
- item_order.xml
- MainActivity.kt
- Drawable XML files
- Bottom Navigation Menu

## Assignment Requirements Covered

- Native Android Development
- XML Layout Design
- RecyclerView UI
- Proper Alignment & Spacing
- Bottom Navigation
- Clickable Buttons/Tabs
